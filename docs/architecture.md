# 运行结构

desktop 提供 Linux 微信与远程桌面。worker 从当前账号的本地数据库读取授权聊天，经群名片映射和正文清理后构造模型请求；回复先经过权限、回合与气泡校验，再执行 UI 发送并回读原生回执。
console 管理模型、人设、会话、聊天白名单、记忆、班务、课表、工具审批和朋友圈。harness 在独立工作区执行工具任务。

## 记忆

- 会话 SQLite 存近期上下文，达到配置容量的 50% 后压缩并保留最近原文。
- 人设 × 会话的 memory.sqlite 存 LangMem 事实、独立原文、每日记忆批次和相处摘要。
- memory_search / memory_read / memory_diary 在调用时检查来源聊天读取权限；原文不常驻提示词。
- 日记调用托管 API，并要求本批原文行号作为依据；失败不推进整理进度，不改人设。
- 历史迁移只接受有来源回执的现存原文；已经删去的原文无法恢复。未确认操作者的历史账号发言不认作 AI 自己的经历。
- 图片只保留短描述用于后续上下文，同一内容不重复识别；不运行本地 embedding 或其他模型。

## 权限与发送

账号绑定、聊天读取/发送/主动权限、当前会话的人设由代码维护。模型输出不能授予权限。
跨聊天发送仍核对目标聊天授权、窗口绑定和原生回执；好友关系操作不会自动创建聊天配置。
系统命令需逐条控制台审批，普通工作区工具不具备宿主权限。
